# Changelog

## 0.1.0

Initial source release:

- Local HTTP service and desktop-style React workbench.
- Kimi ACP integration with dynamic model/thinking choices and native permission requests.
- Global profiles, shared quota display and editable rule-based recommendations.
- Planning, user confirmation, sequential implementation, independent review, one automatic rework and feedback rounds.
- Persistent configuration snapshots, execution details, file previews and explicit interruption recovery.
- Unit, ACP, API, browser and acceptance-example checks; CI for macOS/Linux and Node.js 22/24.

This version supports Kimi only. Other coding agents and a native Mac package remain planned work.
