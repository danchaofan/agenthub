# 任务列表（Todo List）

一个轻量的任务列表网页应用，使用原生 HTML/CSS/JavaScript 实现，零外部运行依赖（无 CDN、无框架）。

## 功能

- 新增任务（点击「新增」按钮或按回车），新增时可为任务选择优先级（高 / 中 / 低，默认「中」）
- 勾选切换任务完成状态
- 删除任务
- 按「全部 / 未完成 / 已完成」筛选完成状态
- 按「全部 / 高 / 中 / 低」筛选优先级；状态筛选与优先级筛选可组合使用（例如「未完成」+「高」只显示未完成的高优先级任务）
- 列表项以徽标展示任务优先级（高 = 红、中 = 琥珀、低 = 灰）
- 数据通过 `localStorage` 持久化，刷新页面后任务、完成状态与优先级均保留（当前筛选状态不持久化）

## 旧数据兼容

历史版本保存的任务数据（不含 `priority` 字段）可以正常读取：读取时自动补齐为默认优先级「中」；数据中非法的优先级值也会被规整为「中」。

在每条任务右侧选择新的优先级，可以修改已有任务；修改随数据保存，当前筛选条件会立即重新应用。

## 启动方式

直接用浏览器打开 `index.html` 即可使用，无需任何构建或安装步骤。

也可以选择一个本地静态服务方式访问，例如：

```bash
# Python 3
python3 -m http.server 8000

# 或 Node.js（需另行安装 serve，可选）
npx serve .
```

然后访问 `http://localhost:8000`（以实际端口为准）。

## 运行测试

业务逻辑模块 `store.js` 配有基于 Node.js 内置测试框架 `node:test` 的单元测试。

要求 Node.js 版本 **18+**（`node --test` 自 Node 18 起稳定可用），在本目录执行：

```bash
node --test
```

或使用 npm 脚本：

```bash
npm test
```

测试为纯 Node 环境运行，不依赖浏览器与 DOM。

## 文件结构

| 文件            | 说明                                                                                                                                                         |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `index.html`    | 页面结构，中文界面                                                                                                                                           |
| `style.css`     | 页面样式                                                                                                                                                     |
| `app.js`        | 页面交互与 `localStorage` 持久化逻辑                                                                                                                         |
| `store.js`      | 业务逻辑模块（UMD：浏览器挂到 `TodoStore` 全局，Node 中可 `require`），不含 DOM/localStorage 依赖                                                            |
| `store.test.js` | `node:test` 单元测试，覆盖新增（含优先级默认值与非法值回落）、完成切换、删除、状态筛选与优先级组合筛选、`setPriority`、序列化/反序列化、旧数据兼容及异常输入 |
| `package.json`  | 声明本目录为 CommonJS（与父目录 ESM 配置隔离），并提供 `npm test` 脚本                                                                                       |
